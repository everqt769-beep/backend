Estructura de la base de datos (esquema public)
A continuación tienes todas las tablas del esquema public, con campos, PK y FK (relaciones) según el introspectado actual.

public.estados
PK: id_estado (uuid)
RLS: false
Campos:

id_estado uuid

codigo text (unique)
nombre text
color varchar (nullable) (check formato #RRGGBB)
descripcion text (nullable)
FK:

seguimiento.estado_nuevo_id → estados.id_estado
reportes_historial.estado_id_original → estados.id_estado
asignaciones.estado_id → estados.id_estado
adjuntos.estado_moderacion_id → estados.id_estado
reportes.estado_id → estados.id_estado
usuarios.estado_id → estados.id_estado

public.bloqueos_usuario
PK: id_bloqueo (uuid)
RLS: false
Campos:

id_bloqueo uuid
usuario_id uuid (NOT NULL)
reporte_id uuid (nullable)
motivo text (NOT NULL)
tipo text (NOT NULL) (check: manual|automatico_ia)
strikes_acumulados int (NOT NULL, default 1)
fecha_bloqueo timestamptz (NOT NULL, default now())
fecha_desbloqueo timestamptz (nullable) — NULL = permanente
desbloqueado_por uuid (nullable)
fecha_desbloqueado timestamptz (nullable)
activo boolean (NOT NULL, default true)
notas_admin text (nullable)
FK:

bloqueos_usuario.usuario_id → usuarios.id_usuario (ON DELETE CASCADE)
bloqueos_usuario.reporte_id → reportes.id_reporte (ON DELETE SET NULL)
bloqueos_usuario.desbloqueado_por → usuarios.id_usuario
public.configuracion_bloqueos
PK: id (int, default 1, check id = 1) — Tabla singleton (1 sola fila)
RLS: false
Campos:

id int (default 1)
auto_bloqueo_ia boolean (NOT NULL, default false)
strikes_para_bloqueo int (NOT NULL, default 1)
duracion_primer_strike_horas int (NOT NULL, default 24)
duracion_segundo_strike_horas int (NOT NULL, default 72)
duracion_tercer_strike_horas int (NOT NULL, default 0) — 0 = permanente
telefono_contacto text (NOT NULL, default '222-0000')
mensaje_bloqueo text (NOT NULL, default 'Su cuenta ha sido suspendida...')
updated_at timestamptz (default now())
FK: ninguna

Nota sobre estados de usuario:
- activo: Usuario puede reportar y comentar
- bloqueado: Usuario no puede usar el sistema
- suspendido: Usuario suspendido temporalmente por reportes falsos (NUEVO)

Relaciones principales (resumen)
areas (1) → categorias (N)
areas (1) → usuarios (N)
estados (1) → reportes (N), usuarios (N), asignaciones (N), seguimiento (N), adjuntos (N)
usuarios (1) → reportes (N), comentarios (N), adjuntos (N), asignaciones (N) (como funcionario), seguimiento (N), bloqueos_usuario (N)
categorias (1) → reportes (N)
reportes (1) → comentarios (N), adjuntos (N), seguimiento (N), asignaciones (N), reportes_historial (N), bloqueos_usuario (N)
reportes (1) ↔ analisis_ia (1) (por reporte_id unique)
configuracion_bloqueos → singleton (1 fila, configuración global de bloqueos)
